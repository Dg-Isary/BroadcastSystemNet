# 📢 智能校园广播系统 (BroadcastSystem)

一款基于 `.NET 8` 构建的现代化、轻量级且极具安全性的校园/企业广播播控系统。本项目采用 C# WinForms 作为原生服务端底座，内嵌 ASP.NET Core 提供高性能 Web API，并配有精美的响应式 Web 播控前端。

无论是定时打铃、课间操歌单循环，还是应对复杂的中国式“调休补班”，本系统都能轻松胜任。

## ✨ 核心特性

* 🖥️ **双端协同控制**：提供 C# 原生防截断桌面管理端 + 纯静态高颜值 Web 控制端（支持 PC 与移动端自适应）。
* ⏰ **强大排程与调休引擎**：支持按星期循环、指定日期覆盖，并内置云端/本地双轨“调休标记”仲裁机制，轻松应对各种复杂作息。
* 🎵 **无缝断点续播**：支持文件夹批量推流与记忆播放，上次播到哪，下次接着播。
* 🛡️ **极客级安全防护**：内置严格的路径防穿越机制、死循环/坏文件跳过机制、密码单向 SHA-256 哈希加密及安全的 JWT 会话管理。
* 📊 **硬件与波形监控**：Web 端实时渲染音频波形，并实时监控服务端主机 CPU 与物理内存负载。

## 🛠️ 安装说明与环境准备

> **⚠️ 核心警告：为避免仓库体积过大及潜在的版权纠纷，本开源仓库不包含任何音频文件、自定义图标以及 FFmpeg 可执行文件。运行前请务必完成以下补全操作！**

### 1. 准备运行环境

* 确保你的开发机或服务器已安装 [.NET 8.0 SDK 或 Desktop Runtime](https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0)。

### 2. 补全核心发声引擎 (FFmpeg)

本系统的音频解码和播放深度依赖 FFmpeg 组件。请自行下载并在指定目录放置它们：

1. 前往 FFmpeg 官网或 [Gyan.dev](https://www.gyan.dev/ffmpeg/builds/) 下载 Windows 编译版的 FFmpeg。
2. 在本项目的 `res` 文件夹下创建一个名为 `bin` 的子文件夹（即 `res/bin/`）。
3. 将解压后的 **`ffmpeg.exe`** 和 **`ffplay.exe`** 放入 `res/bin/` 目录中。
*(若缺少这两个文件，系统将无法发出任何声音，实时波形也将失效！)*

### 3. 准备音频素材 (可选)

* 在 `res/` 目录下创建 `ring` 文件夹（`res/ring/`）。
* 将你自己合法的 `.mp3` 或 `.wav` 铃声文件放入其中，方便在系统中一键扫描导入。

### 4. 编译与运行

* 使用 Visual Studio 2022 打开项目 `.csproj`，直接按下 `F5` 编译运行。
* 或在命令行执行：`dotnet run`。

## 📖 使用说明

### 1. 本地音频管理 (C# 桌面端)

启动程序后，点击主界面的 **“本地音频管理”**：

* 你可以通过“导入文件”或“扫描默认铃声库”将音乐装载进系统。
* 所有音乐会自动连号（ID 1, 2, 3...），你可以通过左下角的**上移/下移**按钮灵活调整歌单顺序。
* 修改完毕后，务必点击右下角 **“保存配置并应用”**，数据将瞬间同步至 Web 前端。

### 2. 云端调休配置 (C# 桌面端)

对于拥有多个校区或需要统一管理作息的用户：

* 点击主界面的 **“云端调休配置”**，填入包含合法 JSON 数组的 URL。
* 设定好轮询周期后，系统会在后台静默为你同步所有调休数据。

### 3. 网页播控看板 (Web 端)

* 程序运行后，浏览器访问 `http://127.0.0.1:5000` (局域网内可通过服务器 IP 访问)。
* 默认无密码。你可以点击右上角 ⚙️ **系统设置** 设置安全锁密码。
* **任务排程表**：点击“新增任务”安排你的定时打铃或歌单。
* **手动播控中心**：点击“+”号将配置好的音乐或文件夹推入队列，支持单曲循环、列表循环、断点顺序播放等多种模式。

### 4. 自定义个性化图标

* 准备一个 `.ico` 格式的图标文件。
* 将其重命名为 `favicon.ico` 并放置在 `res/` 目录中。
* 重新启动程序，C# 主窗体、各个弹窗以及右下角托盘图标将自动全局替换为你的专属图标。

## ⚠️ 注意事项

1. **防火墙设置**：如果需要在局域网内的手机或其他电脑上访问 Web 控制台，请在 Windows 防火墙中放行 **TCP 5000 端口**；若需使用对讲广播功能，请一并放行 **TCP 7000 端口**。
2. **路径规则**：在音频管理中手动填写路径时，支持相对路径（基于 `BaseDir`）和绝对路径（如 `D:\Music\...`）。系统内置了严格的安全沙盒，非法的相对路径（试图跨越系统盘的 `../../`）将被自动阻断。
3. **紧急停播**：如果遇到意外情况需要立刻切断声音，可以通过 Web 端的“红色电源键”或电脑右下角托盘菜单的“紧急停用”瞬间杀死所有播放进程。
4. **对讲功能已移除，如需要请回退1.0.0分支**
